polish(text): 收敛掩码遗留的 113 处空格病句与 6 处别扭措辞

上一轮品牌中性化是把 "DSH" 直接替换成 "宿主"，留下了 "本地 宿主""电脑端 宿主"
"重启 宿主" 这类中文之间的多余空格（共 113 处，分布在 py/ts/dart/插件注释里），
另有几处替换后语义重复的句子。

处理：
- 用带后顾的正则 (?<=[\u4e00-\u9fff]) 空格 宿主 → 宿主 收敛，
  只处理"汉字+空格+宿主"，不动 "本地 Agent 宿主" 这类拉丁词前的正常空格；
- lxai_bridge.py 首行 "本地 Agent 宿主本地安全反向桥接客户端 (本地宿主 Bridge v3.6)"
  → "本地 Agent 宿主安全反向桥接客户端 (LxAI Bridge v3.6)"；
- 桥接日志里 4 处别扭措辞：
  "宿主 Local Reverse Bridge v3.7" → "LxAI Bridge 本地反向桥接 v3.7"
  "宿主本地反向桥接客户端" → "LxAI Bridge 本地反向桥接客户端"
  "调用本地 Agent 宿主 Agent" → "调用本地 Agent 宿主的模型"
  "连接本地 Agent 宿主 / Agent 服务失败" → "连接本地 Agent 宿主服务失败"；
- 桥接自报的 clientName 由 "本地宿主-Harness-Local" 改为 "LxAI-Bridge-Local"，
  与中继侧默认 agent 名保持一致（中继日志里此前显示的是两套名字）；
- App 导出 bat 的两处用户可见文案去空格。

顺带定位并修掉一个会让用户直接踩坑的问题（见上一个提交）：这些脚本模板
换行天生是 LF，落盘成 .bat 后 cmd 会吃掉字符，双击即报错。
