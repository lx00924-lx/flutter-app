## 一、三档分类

任何扫出来的候选，先归到这三档之一，**不要凭文件名判断**。

### 第 1 档：直接删

| 特征 | 为什么安全 | 判据 |
| --- | --- | --- |
| `*.bak-*` 且已经部署验证过 | 备份的意义是"回滚到上一个能用的版本"，版本确认没问题后备份就失效了 | 当前文件能跑通 + 备份时间早于当前文件 |
| 构建日志 / 排查日志（`build-*.log`、`_pd-watch*.log`、`*-scan.log`） | 一次性产物 | 文件名带日期且已过期 |
| 0 字节文件 | 从来没有内容 | 长度 = 0 |
| 应用启动日志（`.dsh\logs\startup-*.log`） | 每次启动生成一份，只对当次排查有用 | 不是最新的那份 |
| 安装备份目录（`%LOCALAPPDATA%\LxAI-backup-*`） | 每次装 Windows 版前整份复制一份，连调 8 次就是 8 份 | **只留最新一份**，其余全删 |
| 旧安装包 / 旧 APK | 新包已经装上了，旧包只是占地方 | 时间早于最近一次装机 |
| 测试沙箱目录（`.sandbox-demo\`） | 安全测试的产物，里面的 key 是假的 | 确认没进过 git + gitignore 已挡 |

### 第 2 档：移走，不删

| 特征 | 移到哪 | 理由 |
| --- | --- | --- |
| `messages_data\*.json.bak-*` | `F:\ai\backup\messages_data-bak-<日期>\` | **数据库迁移前的唯一回退点**，受保护目录，但留在生产目录会混淆 |
| 旧安装器 / 旧 exe（`LxAI-Setup-*.exe`、`LxAI.exe`） | `F:\ai\backup\installers\` | 官网分发要用，删了要能重打；但版本号对得上不代表内容还新 |
| 损坏的数据文件（`*.corrupt-*`、`*.broken-*`） | `F:\ai\backup\` | 坏文件本身没用了，但保留证据以便追溯是什么时候坏的 |

### 第 3 档：永远不动

**这些扫出来一律跳过，不要当垃圾上报。**

| 路径 | 为什么 |
| --- | --- |
| `messages_data\lxai.db*`（含 `-wal` / `-shm`） | 全部业务数据 |
| `messages_media\` | 用户发的图 / 语音，随机文件名，删了不可恢复 |
| `messages_data\settings_media\` | 当前在用的背景图 / 头像 / 启动图 |
| `.env`、`.secrets\master.key` | 凭据 |
| `*.jks`、`key.properties` | 签名密钥，删了打不出正式包 |
| `server-run.log` **和 `.log.1`** | 当前日志 + **轮转目标**，删了下次轮转没地方写 |
| `lxai-persona\记忆\*.bak` | 记忆档案的历史版本 |
| `F:\ai\backup\` 本体 | 备份目录 |
| `docs\*.md`、`scripts\test-*.mjs` | 文档与测试脚本，不是垃圾 |

## 二、容易误判的三类

### 2.1 `.log.1` 不是旧日志

`server-run.log` 满 5 MB 就轮转成 `.log.1`，**`.log.1` 是下一次轮转的落点**。
删了它，下次轮转要么失败、要么直接截断当前日志。

**判据**：只有 `.log.old`（如果有）才是真正可删的历史。

### 2.2 "测试脚本"不是垃圾

`_test-*.mjs`、`_test-*.py`、`verify-*.mjs` 是常驻的验收脚本，**每次改完都要跑**。
它们体积小（几十 KB），删了下次要重写。

### 2.3 备份目录的"最近一份"要看时间，不看数量

`LxAI-backup-*` 在 11-16 那天连打了 8 份（间隔十几分钟），**8 份里 7 份是同一个中间态**。
留"最新一份"就够，不用留"N 天内的"。

## 三、一条命令扫 + 一条命令清

### 扫描（只读，先看清单）

```powershell
$c = @()
$c += Get-ChildItem "$env:LOCALAPPDATA" -Directory -Filter 'LxAI-backup-*' |
      Select-Object @{n='类';e={'安装备份'}}, Name, LastWriteTime
$c += Get-ChildItem 'F:\ai\flutter-app' -File -Filter 'server.ts.bak-*' |
      Select-Object @{n='类';e={'server 备份'}}, Name, LastWriteTime
$c += Get-ChildItem 'F:\ai\flutter-app' -File | Where-Object { $_.Name -match '^_pd-watch|^dsh-restart\.log' } |
      Select-Object @{n='类';e={'排查日志'}}, Name, LastWriteTime
$c += Get-ChildItem 'F:\ai\flutter\flutter-app' -File -Filter 'build-2026*.log' |
      Select-Object @{n='类';e={'构建日志'}}, Name, LastWriteTime
$c | Format-Table -AutoSize
```

### 清理（删 1 档 + 移 2 档，**每次跑之前先看扫描结果**）

```powershell
# 装 备 份：只留最新
Get-ChildItem "$env:LOCALAPPDATA" -Directory -Filter 'LxAI-backup-*' |
  Sort-Object LastWriteTime -Descending | Select-Object -Skip 1 |
  Remove-Item -Recurse -Force

# server.ts 备份：留最近 2 份
Get-ChildItem 'F:\ai\flutter-app' -File -Filter 'server.ts.bak-*' |
  Sort-Object LastWriteTime -Descending | Select-Object -Skip 2 |
  Remove-Item -Force

# messages_data 的 JSON bak → 移走
$d = 'F:\ai\backup\messages_data-bak-' + (Get-Date -Format 'yyyyMMdd')
New-Item -ItemType Directory -Force -Path $d | Out-Null
Get-ChildItem 'F:\ai\flutter-app\messages_data\*' -File -Include '*.bak-*' |
  Move-Item -Destination $d -Force

# 启动日志 / 配置旧备份 / 空文件
Get-ChildItem "$env:USERPROFILE\.dsh\logs" -File -Filter 'startup-*.log' | Remove-Item -Force
Get-ChildItem "$env:USERPROFILE\.dsh\profiles\web" -File -Filter '*.bak*' |
  Sort-Object LastWriteTime -Descending | Select-Object -Skip 1 | Remove-Item -Force
'd.txt','probe.txt','step1.txt' | ForEach-Object { Remove-Item "$env:USERPROFILE\$_" -Force -ErrorAction SilentlyContinue }
```

## 四、两个 PowerShell 陷阱（都踩过）

### 4.1 函数不能叫 `Kill` / `Move`

`Kill` 是 `Stop-Process` 的别名，`Move` 是 `Move-Item` 的别名。
自定义函数取这两个名字 → **调用全部走到内置 cmdlet 上**，结果是"报一堆错、但一个文件没动"。

**用 `RmOne` / `MvOne` 这种不冲突的名字。**

### 4.2 `-Include` 必须配通配符路径

```powershell
# ❌ 返回空
Get-ChildItem 'F:\ai\flutter-app' -File -Include '*.bak-*'

# ✅ 正确
Get-ChildItem -Path 'F:\ai\flutter-app\*' -File -Include '*.bak-*'
```

用 `-Filter` 可以不带 `\*`，但 `-Filter` 只支持单模式、且 `*.bak-*` 这种多段匹配要用 `-Include`。

## 五、删完必须复核

每次清理后**逐条确认**，这 6 项只要有一项不对就说明删错了：

```powershell
Test-Path 'F:\ai\flutter-app\server-run.log'
Test-Path 'F:\ai\flutter-app\server-run.log.1'     # ← 最容易误删
Test-Path 'F:\ai\flutter-app\messages_data\lxai.db'
(Get-ChildItem 'F:\ai\flutter-app\messages_media' -File).Count
(Get-ChildItem 'F:\ai\flutter-app\messages_data\settings_media' -File).Count
netstat -ano | Select-String ':3000\s+.*LISTENING'  # 中继还在听
```

```powershell
Invoke-RestMethod 'http://127.0.0.1:3000/api/health' -TimeoutSec 10
```
